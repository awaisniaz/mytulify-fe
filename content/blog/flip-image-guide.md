## How to use the Flip Image

Upload the original, not a screenshot of a screenshot, if you still have it.

Run it once with the values you have. The result should line up with this promise: Mirror an image horizontally or vertically. Change one field if you want a second case, and keep the other fields the same so you can see what moved.

Look at the edges and the file size of the download. Smaller files throw away detail on purpose.

Keep the units, the dates, and the file type that the form showed. A number from the Flip Image is ready to copy only after you have checked it against the labels on this page.
