## How to use the Crontab Builder

Type the names, ports, and versions from the project you are working on. Example values are not your production values.

Run it once with the values you have. The result should line up with this promise: Build a cron expression and validate it against a real parser, with the next 5 run times previewed. Change one field if you want a second case, and keep the other fields the same so you can see what moved.

## How to read the result

Read the generated file before you apply it. A valid shape can still point at the wrong host or the wrong port.

Keep the units, the dates, and the file type that the form showed. A number from the Crontab Builder is ready to copy only after you have checked it against the labels on this page.

## What the Crontab Builder leaves out

This does not deploy anything and it does not see your cluster. You copy the result into your own toolchain.

Anything the description does not mention is outside this tool. Use the result as the estimate or the file this page promised, then check the source that actually applies to your bank, school, client, or project.
