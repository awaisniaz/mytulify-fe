## How to use the Color Picker

Enter the hex, the RGB, or the two colors the form asks for. A name like “blue” is not a value.

Run it once with the values you have. The result should line up with this promise: Pick any color and get its HEX, RGB, and HSL values. Change one field if you want a second case, and keep the other fields the same so you can see what moved.

## How to read the result

Check the converted value in the place you will use it. A contrast ratio is about those two colors, not about a whole page.

Keep the units, the dates, and the file type that the form showed. A number from the Color Picker is ready to copy only after you have checked it against the labels on this page.

## What the Color Picker leaves out

Screen settings and surrounding colors change what people see. The number is the math for the values you typed.

Anything the description does not mention is outside this tool. Use the result as the estimate or the file this page promised, then check the source that actually applies to your bank, school, client, or project.
