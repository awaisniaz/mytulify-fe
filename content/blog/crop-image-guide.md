Use the free Crop Image to crop images freely or to fixed aspect ratios. This guide explains that job, how to run it, and what the result does not include. The tool itself is here: [Crop Image](/image-tools/crop-image).

## What the Crop Image does

Use the free Crop Image to crop images freely or to fixed aspect ratios.

That is the whole scope of the page. It sits in Image Tools, the group for resize, compress & convert images. The Crop Image only does the job in that first sentence.

Crop Image runs in your browser. The file or the figures stay on your device, and the free plan does not ask you to create an account.

## When a Crop Image is the right page

Use it when you have the picture and you need a different size, format, or crop.

Open it when you need to crop images freely or to fixed aspect ratios. If you need a different output, pick the tool whose description names that output.

## How to use the Crop Image

Upload the original, not a screenshot of a screenshot, if you still have it.

Run it once with the values you have. The result should line up with this promise: Crop images freely or to fixed aspect ratios. Change one field if you want a second case, and keep the other fields the same so you can see what moved.

## How to read the result

Look at the edges and the file size of the download. Smaller files throw away detail on purpose.

Keep the units, the dates, and the file type that the form showed. A number from the Crop Image is ready to copy only after you have checked it against the labels on this page.

## What the Crop Image leaves out

The page cannot recover pixels that were never in the file you uploaded.

Anything the description does not mention is outside this tool. Use the result as the estimate or the file this page promised, then check the source that actually applies to your bank, school, client, or project.
